# Proteínas: las piezas que trabajan

Interactivo de apoyo para **Temas Selectos de Química · Unidad III · 3.4 Proteínas** (características, aminoácidos y enlace peptídico, estructura y desnaturalización, clasificación, función biológica, metabolismo y alimentos). Preparatoria Xochicalco.

- 8 estaciones con barra de progreso: anatomía del aminoácido (glicina vs. valina), constructor del enlace peptídico, niveles de estructura, laboratorio del huevo (desnaturalización), clasificación, función biológica, viaje de la proteína y alimentos, y quiz con cierre.
- Las actividades se pueden repetir sin límite; el avance se guarda en el navegador.
- Al final se genera un **comprobante en PNG o PDF** (nombre, grupo, aciertos por actividad, explicación del enlace peptídico y respuesta para Mateo) para subir a Blackboard.
- Un solo archivo (`index.html`), sin dependencias externas.

Caso ficticio con fines educativos; no sustituye una consulta médica o nutricional.

Para publicarlo: *Settings → Pages → Deploy from a branch → main / (root)*.
